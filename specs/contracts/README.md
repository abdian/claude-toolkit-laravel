# contracts — قرارداد سرویس‌های بیرونی

یک فایل OpenAPI 3.0 برای هر سرویس بیرونی که بهش وصل می‌شیم.

**این قراردادها مال ما نیستن.** ما مصرف‌کننده‌ایم، نه صاحب. پس:

- اینجا چیزی «تصمیم‌گیری» نمی‌شه — چیزی که طرف مقابل مستند کرده ثبت می‌شه.
- منبعش مستند رسمی همون سرویسه. هرچی اینجاست باید قابل ردیابی به اون باشه.
- هر endpointـی که تو `INTEGRATIONS.md` زیر «چی ازش می‌خوایم» نیامده، اینجا
  هم نمی‌آد. کل CRUD طرف مقابل رو کپی نکن.

## به چه دردی می‌خوره

1. **نوشتن کلاینت.** `app/Services/<Name>Client.php` از روی همین ساخته می‌شه.
2. **فیک کردن تو تست.** `Http::fake()` باید شکلی برگردونه که با این بخونه،
   وگرنه تست سبزه ولی پروداکشن می‌شکنه.
3. **تشخیص تغییر.** طرف مقابل API شو عوض کرد؟ diff همین فایل نشون می‌ده
   کجای کلاینت باید عوض بشه.

## قواعد

1. فقط endpointهایی که واقعاً صدا می‌زنیم.
2. پاسخ‌های خطا رو هم بنویس، نه فقط ۲۰۰ — مخصوصاً ۴۰۹ و ۴۲۲ و timeout.
   رفتار ما موقع هرکدوم، تو `INTEGRATIONS.md` نوشته می‌شه.
3. بالای هر endpoint یه کامنت: تو کدوم فلو یا کدوم صفحه لازم شده.
4. نسخه‌ی API طرف مقابل رو تو `info.version` ثبت کن. عوضش کردن = یه کامیت
   جدا با دلیل.

## فایل‌ها

| فایل | سرویس | وضعیت |
|---|---|---|
| `identity.openapi.yaml` | هویت و ورود | اسکلت — با مستند واقعی طرف مقابل پرش کن |
| `payment.openapi.yaml` | درگاه پرداخت | اسکلت — همون |

سرویس بیرونی جدید؟ اول یه بخش تو `INTEGRATIONS.md`، بعد فایل اینجا.
