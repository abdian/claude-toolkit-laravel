## شکل سیستم

**یک اپ لاراول** که سه پنل را سرو می‌کند و برای چند قابلیت به سرویس‌های
بیرونی وصل می‌شود. آن سرویس‌ها مال ما نیستند و در این ریپو نیستند.

```
        ┌──────────────────────────────────────┐
        │  این اپ (Laravel 13)                  │
        │  سه پنل: کاربر / ادمین / سوپرادمین     │
        │                                       │
        │  app/Services/  ← تنها دروازه خروج    │
        └───────┬───────────────────┬───────────┘
                │                   │
         REST + auth          REST + webhook
                │                   │
                ▼                   ▼
        ┌──────────────┐    ┌──────────────┐
        │  سرویس هویت   │    │ سرویس پرداخت │   ← مال ما نیستند
        └──────────────┘    └──────────────┘
```

جزئیات هر سرویس بیرونی: [`INTEGRATIONS.md`](INTEGRATIONS.md)

## مونولیت، عمداً

یک اپ، یک دیتابیس، یک دیپلوی. سرویس جدا نمی‌سازیم مگر دلیل واقعی پیدا شود
(تیم جدا، الزام مقیاس متفاوت، الزام سازمانی). «شاید بعداً لازم شود» دلیل نیست.

داخل اپ، مرزها با **پوشه و کلاس** کشیده می‌شوند، نه با سرویس و شبکه. اگر
روزی واقعاً لازم شد یک بخش جدا شود، مرزِ تمیزِ داخلی کار جداسازی را ممکن
می‌کند — و تا آن روز هزینه‌ی شبکه و دیپلوی و دیباگ توزیع‌شده را نمی‌دهیم.

## دروازه‌ی خروج — قانون سخت

هر سرویس بیرونی **دقیقاً یک کلاس** در `app/Services/<Name>Client.php` دارد.
هیچ‌جای دیگری `Http::` به بیرون نمی‌زند — نه کنترلر، نه Job، نه کامپوننت.

نتیجه‌اش: تغییر API طرف مقابل = یک فایل. تست = یک `Http::fake()`.
قطعی سرویس = یک جای تعریف‌شده برای رفتار.

## داده

- **DB:** MariaDB (پیش‌فرض) — یک دیتابیس برای کل اپ
- **کش و صف:** Redis (پیش‌فرض) · صف برای هر کار کند یا وابسته به بیرون
- **Session:** Redis
- **پول:** عدد صحیح، واحد ریال. هرگز float، هرگز رشته‌ی اعشاری در کد.
- **تاریخ:** UTC در دیتابیس، تبدیل فقط در لبه‌ی نمایش [Asia/Tehran].
  [تبدیل جلالی با یک helper، یک جا.]
- **شناسه:** جدول‌های داخلی bigint auto-increment. هرچه در URL ظاهر می‌شود
  یا به سرویس بیرونی می‌رود، **ULID/UUID** جدا دارد.
- **داده‌ی سرویس بیرونی:** فقط شناسه‌ی خارجی در یک ستون ساده.
  **بدون FK، بدون join، بدون کش دائمی.** لازم شد، از کلاینتش بپرس.

## Auth

- ورود از طریق سرویس هویت بیرونی. **پسورد و OTP در این اپ ذخیره نمی‌شوند.**
- session روی Redis (اپ وب است، نه API خالص).
- مجوزها طبق [`PERMISSIONS.md`](PERMISSIONS.md)، چک با `can()` نه مقایسه نقش.
- [تصمیم باز: نقش و مجوز از claim داخل توکن می‌آید یا جدول محلی؟]
